    Keys for Claude Code sessions

    A session reads the notebook with a key: it can read notes, pick one up, leave a note on it and mark it resolved against its PR. It can't write a note, delete one, or make keys.

    Copy this key now — it's shown once.

    Add it to the Claude Code environment as DEV_NOTEBOOK_KEY: in a Claude Code session, open the cloud environment menu in the title bar → Edit → environment variables. New sessions pick it up. Never paste it into a chat.

    How it works

    • Write: Ctrl+. (⌘. on a Mac) on any studio page, even inside a text field, or the ✎ at the bottom left. Tags are optional; paste or drop screenshots straight into the box.
    • What's recorded: the page, its report and step (never what's typed in a search box), what the page says is open, the window size, and the commit the site was built from. The line under the box shows it before you save.
    • Sessions: npm run notebook lists open notes; --id=… shows one; --set=resolved --pr=57 marks it off. Resolving needs the PR; won't fix, deferred, answered and duplicate need a note.
    • Deleting happens only here. Sessions can't.
